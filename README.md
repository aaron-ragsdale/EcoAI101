# 🌱 EcoAI101

**Small choices, more intentional AI use.**

[**Launch the interactive web app →**](https://aaron-ragsdale.github.io/EcoAI101/)

EcoAI101 introduces responsible and environmentally conscious AI use through six everyday decisions. Choose an option, receive feedback, then reveal its animated AI equivalent.

## What you'll explore

- Right-size the tool: walking, cycling, delivery and dedicated transport.
- Prompt with purpose: a clear grocery list versus vague or excessive instructions.
- Request only what you need: avoid unnecessary output and regeneration.
- Reuse before generating: borrow, find, adapt or create.
- Protect private information: minimize disclosure and check authorization.
- Choose the right format: text, templates, images or video.

## For educators

Use the activity as an individual exploration or a group discussion. Before revealing each AI equivalent, ask learners to predict it. Discuss when another choice might be appropriate. The final toolkit can be copied for reflection.

These analogies illustrate principles rather than measured carbon savings. Privacy is distinct from environmental impact. There is no universal energy ranking of AI brands or model sizes.

## Deployment and privacy

The entire app is in `index.html`. No dependencies, API keys, model inference, analytics, or accounts are needed. Choices remain in page memory. Standard GitHub hosting logs may apply.

Enable GitHub Pages under **Settings → Pages → Deploy from a branch → main → / (root)** if not already configured.
